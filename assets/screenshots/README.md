| Filename | Case study |

**Recommended size:** ~1600×1000 px PNG, compressed via tinypng.com.

If a file is missing, the site automatically shows a polished SVG placeholder for that case study — so you can add them one at a time without breaking the page.

**Privacy note:** make sure any screenshots you publish here have no internal subscription IDs, customer names, or anything you wouldn't want a recruiter to see. The Power BI exports often need a quick crop or blur on row-level data before they're public-ready.
